# ithacashare.org

A one-page, sourced comparison of Cornell's endowment and its voluntary payments to Ithaca governments.

```sh
npm install
npm run dev
```

Pushes to `main` deploy to Cloudflare Workers. See [CONTRIBUTING.md](CONTRIBUTING.md).

This repo is a GitHub template. To start a similar page, click **Use this template**, then change the figures and sources in `public/index.html`, the name and domain in `wrangler.jsonc`, and the OG image.
