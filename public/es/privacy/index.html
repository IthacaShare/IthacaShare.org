Privacidad

Este sitio cuenta las visitas sin cookies. Nunca te pide tu nombre, tu correo electrónico ni ningún otro dato sobre ti.

Qué medimos

Cada página usa Cloudflare Web Analytics, un pequeño script que informa a Cloudflare de cada vista de página. No usa cookies, y Cloudflare dice que “no recopila ni utiliza los datos personales de tus visitantes”. Solo vemos totales: vistas de página y visitas, qué página se vio, el sitio que enlazó a ella, país, navegador, sistema operativo, tipo de dispositivo y qué tan rápido cargó la página.

Alojamiento

Cloudflare aloja este sitio. Como cualquier proveedor de alojamiento web, recibe tu dirección IP y la dirección de la página que solicitas para poder enviártela.

Qué no hacemos

No hay cuentas, formularios ni anuncios, ni rastreadores publicitarios. Los enlaces a otros sitios no les indican que llegaste desde aquí. Los botones “Escribe a” abren tu propia aplicación de correo; nada se envía a través de este sitio.

Si alguien podría estar revisando tu dispositivo

Cualquier sitio web que visites puede aparecer en el historial de tu navegador. Una ventana privada o de incógnito evita que las páginas queden registradas en él. En la página de servicios para sobrevivientes, “Salir de esta página” lleva directamente a un sitio del tiempo, pero no borra tu historial.
